## Решения и обоснования

**Входной формат — Markdown, не DOCX.**
`anonymize` получает уже сконвертированный `.md`-файл из MinIO (путь из `result_payload.md_storage_path` задачи `convert`), а не оригинальный DOCX. Это устраняет дублирование парсинга и делает модуль независимым от формата источника. Следствие: Go-сторона должна цеплять задачи: после `convert completed` создать задачу `anonymize` с `storage_path = md_storage_path`.

**Natasha вместо spaCy для NER.**
Natasha значительно точнее на русских юридических текстах: меньше false-positives на заглавных терминах типа «Стороны», «Объект», «Работы». ORG и LOC из Natasha намеренно отключены — для них используются точные regex с явными маркерами (ООО, г., ул.).

**stdnum для INN/OGRN, не только regex.**
Regex «любые 10 цифр» — слишком широко (ГОСТ-номера, артикулы). `python-stdnum` проверяет контрольную сумму. Пакет называется `python-stdnum` на PyPI (не `stdnum`). Для СНИЛС используется fallback на Mod-101 (ГОСТ Р 54471-2011), так как `stdnum.ru.snils` недоступен в используемой версии `python-stdnum`.

**Ленивая инициализация pipeline.**
`NatashaPipeline` грузит ~50MB эмбеддингов. Singleton создаётся при первом вызове `anonymize()`, не при импорте. Воркеры Celery инициализируют модель один раз при старте процесса.

**`entities_map` в MinIO, не в `result_payload`.**
Маппинг `{<PERSON_1>: "Иванов И.И."}` может быть большим. В `result_payload` Go получает только пути: `anonymized_storage_path`, `entities_map_storage_path`, `entity_count`. Детали доступны по ссылке при необходимости.

## Ловушки и особенности

- **`NatashaPipeline.__new__(NatashaPipeline)`** — способ создать инстанс без загрузки моделей. Используется в тестовой фикстуре `pipeline` для быстрого тестирования regex/stdnum-методов, которые не обращаются к `self.segmenter` / `self.ner_tagger`.
- **Порядок регистрации regex**: `_RE_INN_12` проверяется раньше `_RE_INN_10` — при дедупликации более длинный матч побеждает. Если поменять порядок, 12-значный ИНН физлица будет распознан как 10-значный (с остатком), что сломает checksum.
- **`python-stdnum` vs `stdnum`** — на PyPI пакет называется `python-stdnum`. Попытка установить `stdnum>=1.19` упадёт с «No matching distribution found».
